# Enregistrer ma PFMP

Page d'enveloppe publiée à l'adresse https://enregistrer-pfmp.lycee-les-eucalyptus.org (lien Atrium).
Elle affiche dans un cadre, sans le bandeau Google Apps Script, les pages élèves de la Web App publique verte :

- sans paramètre : formulaire « Enregistrer ma PFMP » (`page=declaration-entreprise`) ;
- `?page=pfmp&rid=…` (ou `token`, `resume`…) : page du QR code de la convention.

Les QR codes imprimés et les liens de l'application visent cette adresse (EUC_LIEN_eleve_ dans EUC_DEV640_Liens.js).
